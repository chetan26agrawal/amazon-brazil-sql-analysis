# Amazon Brazil E-Commerce Analytics

## Project Overview

Analyzed Amazon Brazil's e-commerce data using SQL to generate business insights across customers, sellers, products, orders, payments, reviews, and delivery performance.

## Objectives

- Analyze seller and customer performance
- Evaluate product-category revenue and growth
- Identify customer spending patterns
- Analyze payment method usage and order value
- Evaluate review and delivery performance
- Identify operational and fulfillment gaps

## Tools & Skills

- SQL
- Relational Database Analysis
- JOINs
- CTEs
- Subqueries
- Window Functions
- Aggregate Functions
- CASE Statements
- Date Functions
- Ranking & Analytical Functions

## Key Analysis

- Analyzed order volume by seller state to understand regional fulfillment demand.
- Calculated cumulative revenue by product category over time.
- Compared payment methods based on usage and average order value.
- Identified the highest-spending customer across all orders.
- Calculated average review scores across product categories and customer states.
- Analyzed customer order frequency by state.
- Identified registered sellers with no fulfilled orders.
- Identified the top 5 product categories by total revenue.
- Calculated median delivery time to evaluate typical customer waiting time.
- Identified products that have never been ordered.
- Compared seller performance against the platform-wide average.
- Identified customers who placed orders but never submitted reviews.
- Analyzed monthly order trends to identify the platform's peak order month.

## Business Insights

The analysis provided insights into revenue performance, customer value, seller productivity, regional demand, product performance, payment behavior, customer satisfaction, and delivery efficiency.
